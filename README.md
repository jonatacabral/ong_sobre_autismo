🧠 ONG Vivendo com um Autista

Site informativo e acessível sobre o Transtorno do Espectro Autista (TEA), desenvolvido para conscientização e inclusão.

⸻

📂 Estrutura do Projeto
/html → Páginas HTML (home, diagnóstico, cadastro)
/css  → Estilos gerais e específicos
/js   → Scripts de interação e acessibilidade
/imagens → Recursos visuais otimizados

⚙️ Tecnologias Utilizadas
	•	HTML5 Semântico
	•	CSS3 Responsivo
	•	JavaScript ES6
	•	Git / GitFlow
	•	Acessibilidade WCAG 2.1 AA
	•	Versionamento Semântico

  ♿ Acessibilidade
	•	Navegação por teclado e foco visível
	•	Leitores de tela compatíveis (aria-label, role, etc.)
	•	Contraste mínimo 4.5:1
	•	Modo escuro automático
	•	Botão de modo alto contraste manual

⸻

🧩 Versionamento e Entregas
	•	Branch principal: main
	•	Branch de desenvolvimento: develop
	•	Commits semânticos (feat, fix, docs, style, refactor…)
	•	Releases: versionamento v1.0.0, v1.1.0, etc.

⸻

🗂️ Planejamento
	•	Issues organizadas por tema
	•	Milestones: Entrega 1 (estrutura), Entrega 2 (acessibilidade)
	•	Pull Requests documentados e revisados

⸻

🧱 Otimização de Produção
	•	Minificação de CSS, JS e HTML
	•	Compressão de imagens
	•	Carregamento rápido e responsivo
